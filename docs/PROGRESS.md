## 5. ფუნქციონალი

### 5.1 რეგისტრატურა და პაციენტი
- დღის დაფა: **სვეტები (ექიმები) ↔ სია (დროით)**, ჰორიზონტალური სქროლი, განყოფილების ფილტრი (ინახება მომხმარებელზე)
- ძებნა: პირადი №, გვარი (მიახლოებითი), ტელეფონი; კლავიატურით
- რეგისტრაცია: მოქალაქე / უცხოელი, 11-ციფრიანი ვალიდაცია, **დუბლიკატის გაფრთხილება**
- **მისამართი:** ქალაქი/მუნიციპალიტეტი (ოფიციალური სია) → თბილისის რაიონი / სოფელი (ავტოშევსება) → ქუჩა
- პაციენტის რედაქტირება — აუდიტი ძველი/ახალი მნიშვნელობით
- **დოკუმენტები:** პირადობა, პასპორტი და სხვ. (JPG/PNG/PDF, 10 MB, ტიპი მოწმდება შიგთავსით, კამერით გადაღება ტაბლეტზე; წაშლა არ არის — მხოლოდ დეაქტივაცია)
- ჩაწერა, walk-in, check-in → სალარო

### 5.2 თანხმობები
- ტიპები: პერსონალური მონაცემები, ხილულობა სხვა კლინიკისთვის, SMS, ინფორმირებული თანხმობა (ვიზიტზე)
- ხელმოწერა: **ელექტრონული** (ტაბლეტი/პადი → ხელმოწერილი PDF) ან **ქაღალდი → სკანი**; მეთოდს კლინიკა ირჩევს
- კანონიერი წარმომადგენელი, უარი, გაუქმება, **ტექსტის ვერსიები**

### 5.3 სალარო
- გადასახდელების სია, ინვოისის ხაზები, ნაღდი / ბარათი (ტერმინალის №) / გადარიცხვა
- ფასდაკლება — მხოლოდ დასაბუთებით (DB დონეზეც)
- გადახდა → ვიზიტი აქტიურდება (ექიმთან / სისხლის აღებაზე)

### 5.4 ექიმის სამუშაო სივრცე
- ალერგიების ბანერი, ვიტალები, ჩივილები/ანამნეზი/სტატუსი **ავტომატური შენახვით**
- ICD-10 ძებნა; "*" კოდი ძირითადად დაბლოკილია
- **დანიშნულება ალერგიის ცოცხალი შემოწმებით:** მძიმე/საშუალო/აუტანლობა × პირდაპირი/ჯვარედინი → ინფორმაცია / გაფრთხილება / დასაბუთება / დაბლოკვა + დადასტურება
- **დიაგნოსტიკის შეკვეთა** კატალოგიდან (ლაბორატორია / რადიოლოგია / ენდოსკოპია), სასწრაფო, შენიშვნა; კონტრასტის ალერგიის შემოწმება
- ლაბ. შედეგი ჩანს **მხოლოდ ვალიდაციის შემდეგ**
- მიმართვები (კონსულტაცია, ჰოსპიტალიზაცია), წინა ვიზიტები, დასრულების ჩამონათვალი
- **ფორმა №IV-100/ა:** ველები EMR-იდან (მათ შორის ლაბ. გადახრები და რადიოლოგიის დასკვნები), PDF + QR, საჯარო ვერიფიკაცია, გაუქმება

### 5.5 დიაგნოსტიკა და ლაბორატორია
- **კატალოგი:** 17 ანალიზი (46 კომპონენტი), 22 რადიოლოგიური, 5 ენდოსკოპიური — ⚠️ შაბლონი, გადასამოწმებელი
- თითო კვლევა = საკუთარი ტარიფი = ინვოისის ხაზი
- **ლაბ. ვიზიტი ექიმის გარეშე** (რეგისტრატურიდან, გარე მიმართვით); 0 ₾ — მაშინვე აქტიური; ყველა შედეგის შემდეგ ავტომატურად იხურება
- **ფლებოტომია:** რიგი (სასწრაფოები ზემოთ, გადახდის სტატუსი), იდენტიფიკაციის სავალდებულო დადასტურება, სინჯარები **აღების რიგით** (Citrate → Serum → Heparin → EDTA → Fluoride), სტიკერები 50×25 მმ (Code128), "ვერ აიღო"
- **ლაბორატორია:** მიღება შტრიხკოდის სკანირებით, შედეგები ნორმებით (სქესი/ასაკი), ↑↓ / კრიტიკული ნიშნები, შუალედური შენახვა, **ვალიდაცია**, შესწორება დასაბუთებით, **ბლანკი PDF**
- **ანალიზების ფორმები:** ლაბ. მენეჯერი/ხელმძღვანელი ქმნის ანალიზს, კომპონენტებს, ნორმებს; ნორმებს ამტკიცებს ლაბ. ექიმი; ფასს — admin/მოლარე
- **რადიოლოგია / ენდოსკოპია:** სამუშაო სია, დასკვნის შაბლონები, Accession Number (A100001…)

### 5.6 ადმინისტრირება
მომხმარებლები (AD/ლოკალური, დროებითი პაროლი ერთხელ, განბლოკვა, სესიების დახურვა), განყოფილებები, ტარიფები + მიმართვების ტარიფები, კვლევების კატალოგი, კლინიკის რეკვიზიტები + ხელმოწერის მეთოდები, თანხმობების ტექსტები, ალერგენები, override-ების რეპორტი, აუდიტ-ჟურნალი.
